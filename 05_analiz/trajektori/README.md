# Önceden Hesaplanmış Trajektoriler

Oturum 5'te analiz edilecek simülasyon çıktıları bu dizine yerleştirilecektir.

| Dosya | İçeriği |
|---|---|
| `md.tpr` | Çalıştırma girdisi (topoloji ve parametreler) |
| `md.xtc` | Trajektori (sıkıştırılmış koordinatlar) |

**Dosya boyutu kısıtı.** GitHub tek dosya için 100 MB üst sınırı uygulamakta,
50 MB üzerindeki dosyalar için uyarı vermektedir. Trajektori dosyasının bu
sınırı aşması hâlinde bu belgeye Zenodo veya Google Drive bağlantısı eklenecek,
not defterleri dosyayı ilgili adresten indirecektir.

**Gerekçe.** Kursta üretim simülasyonu koşulmamaktadır; bir günlük süre içinde
bu mümkün değildir. Oturumların odağı sistem kurulumu olup, analiz oturumunda
önceden hesaplanmış çıktılar üzerinden trajektori değerlendirme ölçütleri ele
alınmaktadır.

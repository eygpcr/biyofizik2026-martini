# Hazır Trajektoriler

Oturum 5'te analiz edeceğimiz hazır simülasyon çıktıları buraya konacak.

| Dosya | Ne |
|---|---|
| `md.tpr` | çalıştırma girdisi (topoloji + parametreler) |
| `md.xtc` | trajektori (sıkıştırılmış koordinatlar) |

> ℹ️ **Dosya boyutu:** GitHub tek dosya için 100 MB sınırı koyar (50 MB'da uyarır).
> Trajektori büyükse buraya Zenodo/Drive bağlantısı konacak ve notebook oradan indirecek.

**Neden hazır trajektori?** Kursta uzun simülasyon koşmuyoruz — bir günde
mümkün değil. Odağımız input hazırlama; analiz oturumunda ise hazır çıktı
üzerinden "bir trajektoriye hangi soruları sorarız?" sorusunu işliyoruz.
